SiliconWin guest tools
======================

These tools were installed automatically when Windows was set up by SiliconWin.

  * VirtIO drivers (network, random number generator, serial channel, memory balloon)
  * SiliconWin agent (shares the clipboard with the Mac)
  * Power settings suited for a virtual machine (no sleep, no hibernation)

To reinstall, open the SILICONWIN disc and run SiliconWin\install.cmd as administrator.
The agent lives in "C:\Program Files\SiliconWin\agent.ps1" and starts at every sign-in.
